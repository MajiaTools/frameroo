## What it does

- **5 个可走动的三维练习场景**：江南庭院、高山草甸、伊犁远山、山湖来信、群峰的呼吸
- **在场景里移动机位**，调整朝向、画幅和人物站位，把构图真正练到手上
- **按下快门**，照片和拍摄参数自动保存在「最近的快门」，随时回看对比
- **也可以请 AI 点评**，看看哪里还能更好，然后再试一次
- 场景支持双人移动 / 自由行走 / 旅行人像等不同练习方式，封面均为模拟器拍摄示例

## How to use

1. 打开 https://frameroo.online，选一个喜欢的场景
2. 在场景里走动、换一种构图，把人物放进画面，按下快门
3. 在「最近的快门」里回看照片、对比拍摄参数，也可以请 AI 点评后再试一次
